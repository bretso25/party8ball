🏆 Annual Championship

Year-End Tournament

Five divisions seeded by skill. Double elimination throughout. Every open table gets used — no division waits around while tables sit empty. A C or D team can walk away with $10k.

🎱 How Z Runs It
The organizer fills every available table every night. As teams get eliminated, tables open up and the next division's matches bleed in. C bracket (all 16 teams) runs first — by mid-week, open tables from C eliminations get filled with D bracket matches. This means roughly 2.5 divisions run simultaneously by the end of each week. Nobody sits around, no tables go to waste, and no single group grinds 5 nights in a row.
